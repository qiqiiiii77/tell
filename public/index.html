You’re on the hosted demo. The gate itself is pure client-side code, so everything in the Gate panel is the real scoring engine, running in your browser right now — press those four buttons. A live call also needs a server to mint AssemblyAI tokens, so Start call is disabled here. To talk to the agent: git clone the repo, add a key, npm start. Or run node tools/simulate-call.mjs for the whole loop with no microphone.
